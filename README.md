# ArtNails Academy  
### *Курсовая работа по дисциплине «Системы управления базами данных»*

## Аннотация
Проект **ArtNails Academy** представляет собой веб‑платформу для дистанционного обучения в области нейл‑индустрии. Система разработана в рамках выполнения курсовой работы в колледже по дисциплине **«Системы управления базами данных»**.

Цель проекта — создание программного комплекса, обеспечивающего хранение, обработку и предоставление учебных материалов, а также реализацию механизмов тестирования и отслеживания прогресса пользователей.

Разработка демонстрирует навыки проектирования реляционной базы данных, построения клиент‑серверной архитектуры, создания пользовательского интерфейса и интеграции внешних сервисов.

---

## Цели и задачи проекта
В рамках курсовой работы были выполнены следующие задачи:

- разработка структуры базы данных для хранения информации о пользователях, курсах, модулях, тестах и результатах обучения;
- реализация веб‑интерфейса для взаимодействия пользователей с системой;
- создание механизма регистрации, авторизации и персонализации данных;
- разработка функционала просмотра курсов, прохождения модулей и выполнения тестов;
- внедрение системы оценки знаний и выдачи сертификатов;
- обеспечение корректной работы CRUD‑операций и взаимодействия backend‑части с БД.

## Функциональные возможности системы

### 1. Главная страница
- отображение общей информации о платформе и актуальных курсах;
- использование анимаций и динамических элементов интерфейса (JavaScript);
- навигационные элементы для перехода к основным разделам.

### 2. Навигация
- верхнее меню с доступом к разделам: «Главная», «Каталог курсов», «Личный кабинет», «Тестирование» и др.;
- переход между страницами через интерактивные элементы интерфейса.

### 3. Регистрация и авторизация
- создание учётной записи с сохранением данных в базе;
- вход по e‑mail и паролю;
- автоматическое перенаправление в личный кабинет после успешной авторизации.

### 4. Каталог курсов
- отображение всех доступных образовательных программ;
- фильтрация по категориям, уровню сложности и популярности;
- переход к подробной информации о курсе.

### 5. Страница курса
- описание целей, структуры и содержания курса;
- последовательное открытие модулей;
- доступ к тестированию после завершения всех модулей;
- успешное прохождение теста — не менее 70% правильных ответов.

### 6. Оплата курсов
- интеграция с платёжной системой Stripe;
- автоматическое предоставление доступа после успешного платежа.

### 7. Личный кабинет
- просмотр профиля, приобретённых курсов и результатов тестирования;
- редактирование персональных данных;
- скачивание сертификатов после завершения курса.

### 8. Система отзывов
- добавление и удаление собственных отзывов;
- просмотр рейтингов и комментариев других пользователей.

### 9. UX‑компоненты
- анимации загрузки страниц;
- динамическая подгрузка контента;
- улучшенные визуальные элементы интерфейса.
