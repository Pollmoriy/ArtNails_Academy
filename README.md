# ArtNails Academy

### 🎨 Онлайн-платформа для обучения маникюру

**ArtNails Academy** — это интерактивная веб-платформа для обучения мастеров маникюра и новичков. Приложение предоставляет доступ к онлайн-курсам, тестам, практическим заданиям и позволяет отслеживать прогресс пользователя.  

Проект демонстрирует мои навыки работы с базой данных, frontend и backend разработку, Git, а также создание анимаций для улучшения UX.

---

## ⚡ Основной функционал

### 📌 Общие возможности

1. **Главная страница**  
   - Отображает краткую информацию о платформе, актуальные курсы и новости.  
   - Баннеры с курсами, анимации при загрузке страниц (реализованы на JavaScript).  
   - Интерактивные кнопки и элементы навигации.  

2. **Навигация по приложению**  
   - Верхнее меню для перехода к основным разделам: Главная, Каталог курсов, Личный кабинет, Тесты и др.  
   - Переход между разделами осуществляется по нажатию соответствующих кнопок.  

3. **Авторизация и регистрация**  
   - Пользователи создают учетные записи через форму регистрации, вводя необходимые данные.  
   - Вход в систему осуществляется через e-mail и пароль.  
   - После успешной авторизации пользователь автоматически попадает на главную страницу.  

4. **Каталог курсов**  
   - Список всех доступных обучающих программ с краткой информацией и изображениями.  
   - Фильтры и поиск по категориям, сложности и популярности.  
   - Кнопка перехода к подробной странице курса и добавления в «Избранное».  

5. **Страница курса**  
   - Подробное описание курса: цели, программа, структура модулей.  
   - Доступ к каждому модулю открывается последовательно.  
   - Тесты для проверки знаний, доступные после завершения всех модулей.  
   - Успешное прохождение теста — не менее 70% правильных ответов.  

6. **Оплата курсов**  
   - Интеграция с платёжной системой Stripe.  
   - Пользователь вводит платёжные данные на защищённой странице.  
   - После успешного платежа доступ к материалам курса открывается автоматически.  

7. **Личный кабинет**  
   - Просмотр информации о профиле, приобретённых курсах и результатах тестирования.  
   - Редактирование персональных данных.  
   - Возможность скачивания сертификатов после завершения курса.  

8. **Отзывы и рейтинг курсов**  
   - Возможность оставлять и удалять свои отзывы.  
   - Просмотр чужих отзывов, рейтинг по популярности и полезности.  

9. **Анимации и UX**  
   - Плавная загрузка страниц на JavaScript.  
   - Динамическая подгрузка контента для ускорения работы интерфейса.  
   - Интерактивные элементы для улучшения визуального восприятия.  

---

## 🛠 Используемые технологии

- **Frontend:** HTML, CSS, JavaScript (анимации, динамическая подгрузка страниц)  
- **Backend:** Python, Flask  
- **База данных:** SQLite  
- **Система контроля версий:** Git, GitHub  
- **IDE:** PyCharm
